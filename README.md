# HAK Enterprise Design System

Thư viện tiêu chuẩn thiết kế dùng chung cho các ứng dụng HAK.

## Phạm vi
- Design tokens: màu, kiểu chữ, khoảng cách, đường viền và trạng thái.
- Components: điều hướng, dashboard, bảng dữ liệu, bộ lọc, master–detail, modal/drawer.
- Accessibility: bàn phím, focus, responsive và reduced motion.

## Nguồn kế thừa
- `LUONG_HAK` nhánh `design/hak-enterprise-v10-4`, thư mục `design-system`.

## Trạng thái
Repository đang được khởi tạo. Các tiêu chuẩn chi tiết phải được đối chiếu với nguồn trước khi công bố chính thức.
